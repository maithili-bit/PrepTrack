# PrepTrack 🚀

PrepTrack is a full-stack placement preparation platform where users can:

- Track DSA questions
- Manage job applications
- View analytics dashboard
- Store interview notes
- Use secure authentication

---

# ⚙️ Installation

## Clone Repository

```bash
git clone https://github.com/maithili-bit/PrepTrack.git
```

---

## Backend Setup

```bash
cd server
npm install
npm run dev
```

---

## Frontend

Open:
```text
index.html
```

---

# 🔐 Environment Variables

Create `.env` inside `server`:

```env
PORT=5000

DATABASE_URL=your_database_url

JWT_SECRET=your_secret_key
```
